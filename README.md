# Good work has a next day.

A few useful things for working with AI: skills and tools for thinking things through, making things, and picking up where you left off. Take what's useful. Make it yours.

**[Explore the collection and watch the films →](https://michaeljabbour.github.io/)**

### Figure it out
- [Unknowns](https://github.com/michaeljabbour/amplifier-skill-unknowns): Find the question that could change your plan.
- [Research](https://github.com/michaeljabbour/amplifier-skill-research): Build the answer from evidence you can inspect.
- [Long Read](https://github.com/michaeljabbour/amplifier-skill-long-read): Read toward a question without losing the source.
- [Knowledge](https://github.com/michaeljabbour/amplifier-smart-tool-knowledge): Follow a claim back to its evidence.
- [Cognitive Simulation](https://github.com/michaeljabbour/amplifier-skill-cognitive-simulation): Explore a behavioral hypothesis before the study.

### Make a call
- [Market Fit](https://github.com/michaeljabbour/amplifier-skill-market-fit): Shape one clear offer for one customer.
- [Decisioncraft](https://github.com/michaeljabbour/amplifier-smart-tool-decisioncraft): See the choices and the reasoning on one map.
- [Right Shape](https://github.com/michaeljabbour/amplifier-skill-right-shape): Choose the smallest AI shape that fits the job.
- [Intent to Plan](https://github.com/michaeljabbour/amplifier-skill-intent-to-plan): Turn the request into work someone can follow.

### Build something
- [Build with Amplifier](https://github.com/michaeljabbour/amplifier-skill-build-amplifier): Extend Amplifier in the right place.
- [Build with Tauri](https://github.com/michaeljabbour/amplifier-skill-build-tauri): Make the desktop app work beyond the dev server.
- [Build with Torque](https://github.com/michaeljabbour/amplifier-skill-build-torque): Add a domain without tangling the application.
- [Constraint Builder](https://github.com/michaeljabbour/amplifier-skill-constraint-builder): Turn a task rule into a checkable boundary.
- [Forge](https://github.com/michaeljabbour/amplifier-skill-forge): Keep terminal work visible and testable.
- [Desktop Tasks](https://github.com/michaeljabbour/amplifier-skill-desktop-tasks): Finish the desktop step and verify the result.

### Make it better
- [UX Ergonomics](https://github.com/michaeljabbour/amplifier-skill-ux-ergonomics): Make the next step easier to understand and do.
- [Taste × Elegance](https://github.com/michaeljabbour/amplifier-skill-taste): Make it more intentional while keeping it yours.
- [Worth Using](https://github.com/michaeljabbour/amplifier-skill-worth-using): Find what helps someone who did not build it.
- [Preceptor](https://github.com/michaeljabbour/amplifier-skill-preceptor): Keep agent guidance that earns its place.
- [Session Doctor](https://github.com/michaeljabbour/amplifier-skill-session-doctor): Understand a broken session before repairing it.
- [Fast Decisions](https://github.com/michaeljabbour/amplifier-smart-tool-fast-decisions): Measure which agent decisions are worth changing.

### Take it somewhere new
- [Migrate](https://github.com/michaeljabbour/amplifier-skill-migrate): Change the language and preserve the experience.
- [Transfer](https://github.com/michaeljabbour/amplifier-skill-transfer): Bring useful behavior to the app you use.
- [Pipeline](https://github.com/michaeljabbour/amplifier-skill-pipeline): Build a pipeline you can explain and release deliberately.

### Make it visible
- [Imagen Studio](https://github.com/michaeljabbour/amplifier-skill-imagen-studio): Take the image from brief to chosen file.
- [Imagen Provider](https://github.com/michaeljabbour/amplifier-tool-imagen-provider): Use one image interface across configured providers.
- [Sizzle](https://github.com/michaeljabbour/amplifier-skill-sizzle): Direct the film before generating it.
- [TeaserKit](https://github.com/michaeljabbour/amplifier-smart-tool-teaserkit): Re-shoot the product from the same storyboard.

### Pick it up again
- [Amplifier Data](https://github.com/michaeljabbour/amplifier-tool-data): Keep the evidence and change the view.
- [Memory](https://github.com/michaeljabbour/amplifier-skill-memory): Pick up the evidence, not just the summary.
- [Project Handoff](https://github.com/michaeljabbour/amplifier-skill-project-handoff): Pick up where the work left off.
- [Good Teammate](https://github.com/michaeljabbour/amplifier-skill-good-teammate): Get the right help and keep the meaning intact.
- [Team Access](https://github.com/michaeljabbour/amplifier-tool-team-access): See who has access before applying the roster.

Each one has its own job, guide and source. Bring one into your work when it has something to offer.
