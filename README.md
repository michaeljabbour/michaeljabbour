# Good work has a next day.

A question to untangle. A thing to make. A project to pick up again.

I build AI skills and tools for those moments, with the thinking, evidence and next step close at hand.

Take what’s useful. Make it yours.

**[Explore the portfolio](https://michaeljabbour.github.io/)** · [Watch the story](https://michaeljabbour.github.io/#story) · [Browse all 33 capabilities](https://michaeljabbour.github.io/capabilities/)

## Where are you starting?

- **[Figure it out](https://michaeljabbour.github.io/journey/#stage-understand)**: Who is this for, and what do we need to learn?
- **[Make a call](https://michaeljabbour.github.io/journey/#stage-choose)**: What is worth making, for whom, and in what form?
- **[Build something](https://michaeljabbour.github.io/journey/#stage-build)**: What is the first version we can put in front of someone?
- **[Make it better](https://michaeljabbour.github.io/journey/#stage-improve)**: Where does the experience get in someone’s way?
- **[Make it visible](https://michaeljabbour.github.io/journey/#stage-create)**: How can someone see what this is and why it matters?
- **[Take it somewhere new](https://michaeljabbour.github.io/journey/#stage-adapt)**: What needs to carry over when the setting changes?
- **[Pick it up again](https://michaeljabbour.github.io/journey/#stage-continue)**: What will the next person need to keep this going?

Start wherever you are. You don’t need every step or every tool.
